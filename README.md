# Oficina de PDF

Conversor de PDF que roda inteiro no navegador. Nenhum arquivo é enviado para servidor.

**Acesse:** https://thiagobrandao7.github.io/oficina-pdf/

## O que converte

- **Do PDF:** Word (.docx), Excel (.xlsx), imagem (JPG/PNG), texto (.txt) e HTML
- **Para PDF:** imagens, Word, Excel, texto e HTML
- **Arquivamento:** PDF para PDF/A-2b (validado no veraPDF) e PDF/A de volta para PDF comum
- **Organizar:** juntar e dividir PDFs

O site é um único arquivo, `index.html`. As bibliotecas (pdf.js, pdf-lib, JSZip, mammoth, html2pdf.js e SheetJS) são carregadas de CDNs públicas.
